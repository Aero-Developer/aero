Download Aero v0.1.3

Download on GitHub

All builds, checksums and release notes are published on GitHub. Grab the latest Windows portable archive from the releases there.

Windows (64-bit)

Portable — nothing is installed. Extract the archive anywhere and run aero_gui.exe (or run.bat). The bundled Tor client starts automatically; your encrypted wallet is created in a wallets folder next to the program.

Verify your download

Always check the archive's hash before running it.

SHA-256:

32c739cd27de8ab66f1f4a97d4f3970ac9577bbd5736935393db027264e9f40c  Aero-Windows-x64-portable.zip

On Windows (PowerShell):

Get-FileHash .\Aero-Windows-x64-portable.zip -Algorithm SHA256

The printed hash must match the value above. A SHA256SUMS.txt is attached to the release as well.

Linux & macOS

Linux and macOS builds are produced on CI and will be attached to a future release. In the meantime you can build from source — see the build instructions.
